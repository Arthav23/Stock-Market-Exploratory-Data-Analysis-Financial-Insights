# Stock Market Exploratory Data Analysis & Financial Insights

## 📌 Project Overview

This project analyzes historical stock market data to identify price trends,
daily returns, volatility, moving averages, and relationships between stocks.

The objective was to transform raw historical market data into meaningful
financial insights using Python and exploratory data analysis.

## 🛠️ Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 🔍 Analysis Performed

1. Data cleaning and preprocessing
2. Exploratory Data Analysis
3. Stock price trend analysis
4. Daily return analysis
5. Volatility analysis
6. Moving average analysis
7. Correlation analysis
8. Data visualization
